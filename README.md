# Volcano Risk Simulator

지구과학 발표용 **화산 폭발 위험도 시뮬레이터**입니다.

지진 활동, SO₂ 방출 변화, 지표 융기, 열 이상을 조절하면 여러 관측 신호가 동시에 증가할 때 교육용 화산 활동 지수가 어떻게 변하는지 확인할 수 있습니다.

## 실행
GitHub Pages로 배포하거나 저장소의 `index.html`을 브라우저에서 열면 됩니다. 외부 라이브러리 없이 동작합니다.

## 주의
이 프로젝트의 활동 지수는 **실제 분화 확률이 아닙니다.** 실제 화산 감시는 화산별 평상시 기준, 장기 추세, 지진·지표변형·가스·열 관측 등 여러 자료를 전문가가 종합하여 판단합니다.
